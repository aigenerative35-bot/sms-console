    1. Account banao: twilio.com/try-twilio — email, password, apna number verify. Credit card nahi chahiye.
    2. Account SID + Auth Token: console.twilio.com kholo. Neeche Account Info panel me Account SID (AC se shuru, 34 characters) aur Auth Token (Show dabao) milta hai.
    3. From number: Console → Phone Numbers → Manage → Buy a number (trial me free, usually +1 US) — SMS capability wala lo. Ya signup ke end me jo number mila wo.
    4. Apna Indian number verify karo: Console → Phone Numbers → Manage → Verified Caller IDs → Add → +91 number → OTP. Ye step ke bina SMS nahi jayega (error 21608).
