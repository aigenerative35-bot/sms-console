    Free ki sachchai

    Textbelt free key se 1 SMS per day jata hai, aur wo bhi Textbelt ke apne route se. Har number par unlimited free SMS dene wala koi public API exist nahi karta — delivery ka kharcha carrier leta hai.

    Key browser me mat rakho

    Yeh page client-side hai, to paid key bhi browser me visible hoti hai. Production me ek chhota proxy (Node/Express ya Cloudflare Worker) banao, key wahan rakho, aur page ko /api/send par point karo.

    CORS / file:// warning

    Page ko direct double-click karke file:// se kholne par browser origin null bhejta hai aur request block ho sakti hai. Folder me python3 -m http.server 8000 chalao, phir localhost:8000/sms-console.html kholo.

    Bina paise, bina limit

    Apna purana Android phone + apni SIM = genuinely free unlimited. capcom6/android-sms-gateway ya textbee install karo, upar provider me "Own SIM gateway" chuno, aur wahi number gateway dega.

    India rules

    Commercial/bulk ya OTP traffic ke liye TRAI ke DLT registration ki zarurat hoti hai. Personal test messages par ye laagoo nahi hota, par bulk bhejne se pehle check kar lena.

    Kabhi bhi spam nahi

    Sirf apne number ya jiski permission hai usko bhejo. Random numbers par bulk SMS bhejna illegal hai aur number block ho jata hai.
